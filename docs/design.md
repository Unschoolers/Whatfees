# WhatFees marketing page

A mobile-first Vue marketing site for collectors who sell, with focused fee calculator, break-even and TCG inventory pages. Its primary action opens https://app.whatfees.ca; Android links to the existing io.whatfees listing. English and French share layouts with separate, prerendered URLs and crawlable language links.

Use the app's cream, charcoal, gold and red palette, with bold collectible-inspired typography and clean marketplace spacing. Lead with understanding profit after costs and fees. Follow with inventory, pricing and sales; show real app screens using fictional demonstration data. Show real product proof early, explain Free/Pro access, and demonstrate wheel, mystery grid and bracket battles using clearly labeled interactive illustrations. Avoid claims of universal marketplace synchronization, fabricated testimonials or promised earnings.

Keep the site static, without accounts, analytics or a backend. Use GitHub Pages with www.whatfees.ca, leaving app.whatfees.ca unchanged. Verify responsive layouts at 320, 390, 768 and 1440 pixels, both languages, keyboard navigation, FAQ disclosure, image loading and outbound destinations. Build production assets before handoff.
