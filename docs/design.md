# WhatFees marketing page

One mobile-first Vue page for collectors who sell. Its primary action opens https://app.whatfees.ca; Android links to the existing io.whatfees listing. English and French share one layout.

Use the app's cream, charcoal, gold and red palette, with bold collectible-inspired typography and clean marketplace spacing. Lead with understanding profit after costs and fees. Follow with inventory, pricing and sales; show real app screens using fictional demonstration data. Include games as a short audience-engagement section: wheel, mystery grid and bracket battles. Avoid claims of universal marketplace synchronization, fabricated testimonials or promised earnings.

Keep the site static, without accounts, analytics or a backend. Use GitHub Pages with www.whatfees.ca, leaving app.whatfees.ca unchanged. Verify responsive layouts at 320, 390, 768 and 1440 pixels, both languages, keyboard navigation, FAQ disclosure, image loading and outbound destinations. Build production assets before handoff.
